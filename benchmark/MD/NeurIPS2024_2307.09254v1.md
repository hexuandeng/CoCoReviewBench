# Abstract

Uncertainty learning and quantification of models are crucial tasks to enhance the trustworthiness of the models. Importantly, the recent surge of generative language models (GLMs) emphasizes the need for reliable uncertainty quantification due to the concerns on generating hallucinated facts. In this paper, we propose to learn neural prediction set models that comes with the probably approximately correct (PAC) guarantee for quantifying the uncertainty of GLMs. Unlike existing prediction set models, which are parameterized by a scalar value, we propose to parameterize prediction sets via neural networks, which achieves more precise uncertainty quantification but still satisfies the PAC guarantee. We demonstrate the efficacy of our method on four types of language datasets and six types of models by showing that our method improves the quantified uncertainty by  $63\%$  on average, compared to a standard baseline method.

# 1 Introduction

Generative language models (GLMs) [31, 6, 36, 35] have achieved great attention in their abilities of generating human-level languages [22] mainly due to transformer architectures [38]. However, GLMs raise concerns on generating hallucinated facts [17], an unwilling property of GLMs as knowledge retrieval bases. This property can be suppressed by fine-tuning [17, 23] via feeding human-curated data, which is expensive in training and labeling cost. Instead, we leverage uncertainty quantification to alarm the uncertain or provably-wrong responses of GLMs to end-users, without updating GLMs.

Uncertainty quantification aims to measure the uncertainty of model predictions, and conformal prediction [40] is a promising way for quantifying uncertainty as it provides correctness guarantees with finite samples under minimal assumptions. In particular, the goal of conformal prediction is to construct prediction sets on predictions by a given model, where the prediction set is a set of labels that possibly contains a true label of a given example. Here, the prediction set size quantifies the uncertainty of a prediction by the given model (e.g., if the given model is uncertain on a label prediction, the corresponding prediction set is large, providing multiple label choices in classification).

In this paper, we propose to quantify the uncertainty of GLMs via conformal prediction. To this end, we first propose a novel prediction set representation, inspired by the learning theoretic interpretation of conformal prediction [26]. In particular, a prediction set in conformal prediction is parameterized via a scalar variable [24, 26]. This parameterization has shown its efficacy in many practical tasks, including classification and regression [24, 40, 26, 1, 4, 25]. However, we claim that the scalar-parameterized prediction set (SPS) is insufficient to capture better uncertainty in GLMs. Specifically, we wish to mitigate the issue on hallucinated facts of GLMs by providing uncertainty via a prediction set for each token (i.e., token-wise uncertainty) to highlight uncertain tokens in a generated response. # 1.1 Related Work

We introduce related work on uncertainty quantification and its application to GLMs.

Calibration in GLMs. Calibration is one technique to quantify the uncertainty of predicted labels, which goal is predicting the correctness of a given prediction, also called confidence. Calibration is historically explored in forecasting and statistical machine learning [21, 30, 42, 43, 13, 29], where modern neural networks have been empirically identified their overconfidence [13].

In neural language generation, GLMs for question-answering are also demonstrated to be poorly calibrated, and conventional calibration methods (e.g., temperature scaling [30, 13]) partially contribute to address the mis-calibration issue of GLMs [14]. Contrast to the conventional calibration methods (also called probabilistic calibration), the concept of "linguistic calibration" (i.e., generating an answer with a verbalized expression of confidence) is proposed and its effectiveness within generative dialog agents is demonstrated [19]. The aforementioned calibration methods for GLMs are

empirically effective but do not provide the correctness guarantee with finite samples as a basis of trust on quantified uncertainty, while we rely on conformal prediction to quantify uncertainty that comes with correctness guarantees with finite samples.

Conformal prediction. The goal of conformal prediction [40] is to construct a prediction set that likely contains true label, where the set size represents uncertainty. Depending on the problem setups, there are many ways to define and enforce the correctness guarantee in conformal prediction: classification or regression [40, 39, 4], meta learning [10, 27], and online learning [12]. Recently, PAC prediction sets [26] are used to construct prediction sets over partial programs, generated by GLMs of code [16]. One distinguishing feature of conformal prediction is that a prediction set is parameterized in a scalar variable [24, 26, 4], which implies that the scalar parameter is the same regardless of input examples. However, this produces conservative prediction sets in sequential prediction problems. In particular, in language generation, a sequence of prediction sets is generated for each token given a prompt, where each token has a different-level of uncertainty while conformal prediction uses the same scalar parameter for all prediction sets of each token to measure uncertainty; thus, this "coarse" prediction sets tend to be larger. We overcome this issue by considering a high-dimensional parameter via neural networks.

# 2 PAC Prediction Set Learning for GLMs

We consider the problem of learning prediction sets for GLMs. Here, we first provide preliminaries on the problem, followed by our problem statement.

# 2.1 Background: Conformal Prediction and PAC Prediction Sets

Conformal prediction [40] provides a promising way to quantify uncertainty with a correctness guarantee under minimal assumptions. Here, we consider PAC prediction sets [26], an interpretation of tolerance region [41] and training-conditional inductive conformal prediction [39] in the lens of PAC learning theory [37] (i.e., learning a "good" function within a function family from data). This interpretation inspires us to generalize conformal prediction for GLMs.

Prediction Set Models. Let  $\mathcal{X}$  be an example space,  $\mathcal{Y}$  be a label space, and  $D$  be a distribution over  $\mathcal{X} \times \mathcal{Y}$ . We consider a (conformal) prediction set model  $\hat{C}: \mathcal{X} \to 2^{\mathcal{Y}}$  with a scalar parameter [24, 26] as follows:

$$
C (x) := \{y \in \mathcal {Y} \mid f (x, y) \geq \tau \}, \tag {1}
$$

where  $f: \mathcal{X} \times \mathcal{Y} \to \mathbb{R}_{\geq 0}$  is a (conformal) scoring function that measures the conformity (or likelihood) of  $x$  for being  $y$  with respect to  $f$  (thus, we call  $f(x,y)$  a conformity score), and  $\tau \in \mathbb{R}_{\geq 0}$  is a scalar parameter. We denote the family of all prediction sets with a scalar parameter by  $\mathcal{T}$ .

Prediction set and its size. The output of the prediction set model is a set of possible label predictions, constructed to likely include a future label; thus, it is called a prediction set. Here, the size of a prediction set  $|C(x)|$  measures the uncertainty of  $f$  on  $x$ , i.e., if the prediction set size is large (or small),  $f$  is uncertain (or certain) on the label prediction of  $x$ .

From (1), the size is determined by the parameter  $\tau$  given  $f$ , so we maximize  $\tau$  to closely measure the uncertainty of  $f$ , while maintaining that the prediction set  $C(x)$  mostly contains the true label of  $x$  (i.e., learning a "correct"  $C$ ). To this end, we consider the definition of correctness along with a necessary assumption in the following.

Assumption. We assume that samples are independent and identically distributed (i.i.d.) (i.e., the i.i.d. assumption) in this paper. In particular, all samples for testing and learning prediction sets are independently drawn from the same but known distribution  $D$ .

PAC guarantee. Under the i.i.d. assumption, we learn a prediction set  $\hat{C}$  that includes the most true labels (approximately correct), i.e., the expected error of  $\hat{C}$  is less than a desired error level  $\varepsilon \in (0,1)$

$$
L (\hat {C}) := \mathbb {P} \left\{y \notin \hat {C} (x) \right\} \leq \varepsilon ,
$$

where the probability is taken over i.i.d. samples  $(x,y)\sim D$ . Here, the prediction set  $\hat{C}$  is learned from a calibration set, so we desire to construct  $\hat{C}$  that has a desired error most of the time (probably

approximately correct), i.e.,

$$
\mathbb {P} \left\{\mathbb {P} \left\{y \notin \hat {C} (x) \right\} \leq \varepsilon \right\} \geq 1 - \delta , \tag {2}
$$

where  $\delta \in (0,1)$  is a desired confidence level and the outer probability is taken over  $n$  i.i.d. calibration samples  $Z\sim D^{n}$ , used to learn  $\hat{C}$ .

Algorithm. The PAC prediction set approach [26, 28] considers the following algorithm  $\mathcal{A}_{\mathrm{Binom}}$  :  $(\mathcal{X}\times \mathcal{Y})^{*}\to \mathcal{T}^{1}$  to learn a prediction set model  $\hat{C}$ , parameterized by  $\hat{\tau}$ :

$$
\mathcal {A} _ {\text {B i n o m}} ^ {2}: \quad \hat {\tau} = \max  _ {\tau \in \mathbb {R} _ {\geq 0}} \tau \quad \text {s u b j . t o} \quad U _ {\text {B i n o m}} (C, Z, \delta) \leq \varepsilon , \tag {3}
$$

where  $C$  is parameterized by  $\tau$ ,  $\bar{L}_n(C) \coloneqq \sum_{i=1}^{n} \mathbb{1}(y_i \notin C(x_i))$  is the empirical error count of  $C$ ,  $F(k; n, \theta)$  is a cumulative distribution function of a binomial distribution with  $n$  trials and success probability  $\theta$ , and  $U_{\mathrm{Binom}}(C, Z, \delta) \coloneqq \inf \left\{\theta \in [0, 1] \mid F(\bar{L}_n(C); n, \theta) \leq \delta \right\} \cup \{1\}$  is a binomial tail bound, i.e.,  $\mathbb{P}\{L(C) \leq U_{\mathrm{Binom}}(C, Z, \delta)\} \geq 1 - \delta$  for any  $C$ . This algorithm is PAC.

Theorem 1. ([39, 26, 28]) The algorithm  $\mathcal{A}_{\text{Binom}}$  is PAC, i.e., for any  $f, \varepsilon \in (0,1)$ ,  $\delta \in (0,1)$ , and  $n \in \mathbb{Z}_{\geq 0}$ , we have  $\mathbb{P}\{\mathbb{P}\{y \notin \hat{C}(x)\} \leq \varepsilon\} \geq 1 - \delta$ , where the inner probability is taken over a labeled example  $(x,y) \sim D$ , the outer probability is taken over i.i.d. labeled examples  $Z \sim D^n$ , and  $\hat{C} = \mathcal{A}_{\text{Binom}}(Z)$ .

Note that the PAC guarantee generally holds only if an enough number of samples is provided (when we know a function family including a true function). However, we consider PAC algorithms that hold for any number of samples due to the structural property of prediction sets, i.e., a prediction set is always correct if  $\tau = 0$  (thus  $\hat{C}(x) = \mathcal{Y}$ ), regardless of the sample size. In other words, the calibration samples are not sufficient, the prediction set is constructed to return  $\mathcal{Y}$  to satisfy the PAC guarantee. We include a proof in the following.

Proof. Let  $C_{\tau}$  be a prediction set  $C$  with a parameter  $\tau$ ,  $\mathcal{H}_{\varepsilon} := \{\tau \in \mathbb{R}_{\geq 0} \mid L(C_{\tau}) > \varepsilon\}$ , and  $\tau^{*} := \inf \mathcal{H}_{\varepsilon}$ . Then, we have

$$
\begin{array}{l} \mathbb {P} \left\{L \left(\mathcal {A} _ {\text {B i n o m}} (Z)\right) > \varepsilon \right\} = \mathbb {P} \left\{\exists \tau \in \mathcal {H} _ {\varepsilon}, U _ {\text {B i n o m}} \left(C _ {\tau}, Z, \delta\right) \leq \varepsilon \right\} = \mathbb {P} \left\{U _ {\text {B i n o m}} \left(C _ {\tau^ {*}}, Z, \delta\right) \leq \varepsilon \right\} (4) \\ = \mathbb {P} \left\{L \left(C _ {\tau^ {*}}\right) > \varepsilon \wedge U _ {\text {B i n o m}} \left(C _ {\tau^ {*}}, Z, \delta\right) \leq \varepsilon \right\} \leq \mathbb {P} \left\{L \left(C _ {\tau^ {*}}\right) > U _ {\text {B i n o m}} \left(C _ {\tau^ {*}}, Z, \delta\right) \right\} \leq \delta , (5) \\ \end{array}
$$

where the last equality in (4) holds as  $\mathbb{1}\left(y \notin C_{\tau}(x)\right)$  and  $U_{\mathrm{Binom}}$  are non-decreasing in  $\tau$  (i.e., Lemma 2 in [28]) and the last inequality in (5) is due to the property of the binomial tail bound  $U_{\mathrm{Binom}}$ .

# 2.2 Problem Statement

Let  $\mathcal{X}$  be a token space (e.g., a set of tokens in Byte Pair Encoding [11]). Then, we denote an example (or a prompt) by  $\mathbf{x} \in \mathcal{X}^*$ , a label (or a response) by  $\mathbf{y} \in \mathcal{X}^*$ , and a distribution over labeled examples  $\mathcal{X}^* \times \mathcal{X}^*$  by  $\mathbf{D}$ , considering that each prompt has a desired response. Here,  $\mathbf{x}$  (and also  $\mathbf{y}$ ) is a sequence of tokens, i.e.,  $\mathbf{x} := (\mathbf{x}_1, \ldots, \mathbf{x}_l)$ , so we denote its length by  $|\mathbf{x}|$ , i.e.,  $|\mathbf{x}| = l$ , and a sub-sequence from the  $i$ -th token to the  $j$ -th token by  $\mathbf{x}_{i:j}$ .

Our goal is to find a PAC learning algorithm that returns a prediction set model given learning samples. In particular, under the i.i.d. assumption, for any  $\varepsilon \in (0,1)$ ,  $\delta \in (0,1)$ , and  $n \in \mathbb{Z}_{\geq 0}$ , given a family of prediction sets  $\mathcal{F}$ , we find  $\mathcal{A} : (\mathcal{X}^* \times \mathcal{X}^*)^* \to \mathcal{F}$  that satisfies

$$
\mathbb {P} \left\{\mathbb {P} \left\{\mathbf {y} \notin \hat {C} (\mathbf {x}) \right\} \leq \varepsilon \right\} \geq 1 - \delta , \tag {6}
$$

where the inner probability is taken over an labeled example  $(\mathbf{x},\mathbf{y})\sim \mathbf{D}$ , the outer probability is taken over a calibration set  $\mathbf{Z}\sim \mathbf{D}^n$ , and  $\mathcal{A}(\mathbf{Z}) = \hat{C}$ . Along with the PAC guarantee, we wish our algorithm achieving optimal prediction set size, i.e., minimizing  $\mathbb{E}\hat{C} (\mathbf{x})$ , while satisfying (6).

# 3 Neural Prediction Set Models for GLMs

We discuss our proposed method in defining and learning neural prediction set models, along with an algorithm with the PAC guarantee. This section ends with the applications of neural prediction sets in the uncertainty quantification of GLMs.

# 3.1 Recursive Definition of Prediction Sets

We mainly use prediction sets to measure token-wise uncertainty by adopting the recursive definition of prediction sets. In particular, we define the  $l$ -th prediction set  $C_l: \mathcal{X}^* \to 2^{\mathcal{X}^l}$  as follows:

$$
C _ {l} (\mathbf {x}) := \left\{(\mathbf {y}, y) \in C _ {l - 1} (\mathbf {x}) \times \mathcal {X} \mid f ((\mathbf {x}, \mathbf {y}), y) \geq \tau \right\}, \tag {7}
$$

where  $C_1(\mathbf{x}) = \{y \in \mathcal{X} \mid f(\mathbf{x}, y) \geq \tau \}$ . Here, we consider a scoring function  $f: \mathcal{X}^* \times \mathcal{X} \to \mathbb{R}_{\geq 0}$ , which can be any generative language model (e.g., GPT-3 [6]). Note that the size of the prediction set (7) grows exponentially as  $l$  grows, but we mainly consider conditional prediction sets, where the size only grows linearly (see Section 3.5 for details).

# 3.2 Example-dependent Parameterization

The recursive prediction set constructs a prediction set, conditioned on previous labels. However, the scalar parameter  $\tau$  in (7) is used by all prediction sets, i.e., the parameter is example-agnostic, which mainly introduces conservative prediction set size especially for modeling the uncertainty of structured and sequential language generators.

Inspired from the learning theoretical interpretation of conformal prediction [26], we consider the conformal prediction in learning a prediction set among a richer family of prediction sets, parameterized via neural networks. In particular, we design the parameter of prediction sets as the output of any neural network  $\tau : \mathcal{X}^* \to \mathbb{R}_{\geq 0}$ , which depends on previous tokens, instead of a scalar parameter  $\tau \in \mathbb{R}_{\geq 0}$ , which is independent to previous tokens. Thus, our prediction set, parameterized via a neural network, is called a neural prediction set model and defined as follows:

$$
C _ {l} (\mathbf {x}) := \left\{(\mathbf {y}, y) \in C _ {l - 1} (\mathbf {x}) \times \mathcal {X} \mid f ((\mathbf {x}, \mathbf {y}), y) \geq \tau (\mathbf {x}, \mathbf {y}) \right\}, \tag {8}
$$

where  $C_1(\mathbf{x}) = \{y\in \mathcal{X}\mid f(\mathbf{x},y)\geq \tau (\mathbf{x})\}$ . Here, we denote the family of all neural prediction set models by  $\mathcal{F}:= \{C_l:\mathcal{X}^*\to 2^{\mathcal{X}^l}\mid l\geq 1,\tau \in \mathcal{F}'\}$ , where  $\mathcal{F}'$  is any family of neural networks.

# 3.3 Decomposition for a Sample-Efficient PAC Algorithm

Given a family of neural prediction set models  $\mathcal{F}$ , finding a PAC algorithm requires a sample-complexity analysis, i.e., finding a minimal number of samples such that the algorithm chooses a function in  $\mathcal{F}$  with a desired expected error rate with high probability. However, it is generally known that the existing sample-complexity bounds of neural networks are yet to be practical, e.g., the data-independent VC dimension bound is too pessimistic or the width of neural networks should be  $\Omega(n^7)$  (where  $n$  is the number of samples) to have a tighter data-dependent bound than the VC bound [9, 7, 2].

To avoid the high sample-complexity issue, we exploit a structural property of the family of neural prediction sets  $\mathcal{F}$ . In particular, we observe that the ideal shape of  $\tau(\mathbf{x})$  forms a "hammock" to "vertically" support conformity scores  $f(\mathbf{x}, y)$ , as illustrated in Figure 2(b). This observation provides us that if the "shape" of "hammock" is fixed, "vertically translating" the "hammock" can control a desired expected error rate at any level. In this way, we can reduce the search space of  $\mathcal{F}$ , leading to a significantly lower sample-complexity bound. We concretize this idea in the following section.

Decomposition. We consider the following decomposition of a neural prediction set parameter  $\tau (\mathbf{x})$ :

$$
\log \tau (\mathbf {x}) := g (\mathbf {x}) + h, \tag {9}
$$

where  $g:\mathcal{X}^*\to \mathbb{R}$  is a neural network, and  $h\in \mathbb{R}$  is a scalar parameter. Here, we denote a set of all  $g$  and  $h$  by  $\mathcal{G}'$  and  $\mathcal{H}'$ , respectively.

Structural Property. Each component of the decomposed parameter in (9) has its own property. In particular,  $g$  and  $h$  mainly control the size and error of prediction sets, respectively, which is evident if we consider the following reformulation of the scoring function and parameters:

$$
f (\mathbf {x}, y) \geq \tau (\mathbf {x}) \Longleftrightarrow \frac {f (\mathbf {x} , y)}{\exp g (\mathbf {x})} \geq \exp h. \tag {10}
$$

Here,  $g(\mathbf{x})$  contributes to rescaling the scoring function and  $\exp h$  controls the prediction set error given a scoring function, as the scalar-parameterized prediction sets in Section 2.1.

Learning  $h$ . Given  $g$ , learning  $h$  is equivalent to learning prediction sets with a scalar parameter (3); we denote the following algorithm to learn  $h$  by  $\mathcal{A}_h: \mathcal{G}' \times (\mathcal{X}^* \times \mathcal{X}^*)^* \to \mathcal{F}$ .

$$
\mathcal {A} _ {h} (g, \mathbf {Z} _ {h}): \quad \hat {h} = \operatorname * {a r g   m a x} _ {h \in \mathbb {R}} h \qquad \text {s u b j . t o} \qquad U _ {\mathrm {B i n o m}} (\exp h, \mathbf {Z} _ {h}, \delta) \leq \varepsilon ,
$$

where  $\mathbf{Z}_h$  is the calibration set to learn  $h$ . Here, the error of a neural prediction set model on a single example is simplified as  $\mathbb{1}\left(\mathbf{y} \notin C_{|\mathbf{y}|}(\mathbf{x})\right) = \bigvee_{l=1}^{|\mathbf{y}|} f((\mathbf{x}, \mathbf{y}_{1:l-1}), \mathbf{y}_l) < \tau(\mathbf{x}, \mathbf{y}_{1:l-1})$ , which is monotonically non-decreasing in  $h$ , so minimizing this error maximizes the expected size [28].

As the PAC guarantee in Theorem 1 holds for any scoring function, due to the scoring-function reformulation in (10), we have the following PAC guarantee. Appendix A for a proof.

Lemma 1. For any  $g\in \mathcal{G}^{\prime}$ $\mathcal{A}_h$  is  $(\varepsilon ,\delta)$  -PAC.

Learning  $g$ . The neural network  $g$  captures the trend of conformity scores over data. To learn  $g$ , any algorithm is fine as the PAC guarantee holds (as in Lemma 1) regardless of the learning algorithm. However,  $g$  that closely follows the conformity scores of data provides a good uncertainty quantifier in terms of prediction set size. In particular, given  $(\mathbf{x}, y)$ ,  $\tau^{*}(\mathbf{x}) = f(\mathbf{x}, y)$  is the optimal  $\tau$  in the prediction set size. To learn the optimal  $\tau^{*}$ , we consider the learning problem of  $g$  as regression over the conformity scores, i.e., finding  $g$  that minimizes the absolute error between  $f$  and  $g$ . In particular, we consider the algorithm  $\mathcal{A}_{g}: (\mathcal{X}^{*} \times \mathcal{X}^{*})^{*} \to \mathcal{G}'$  that solves the following standard regression problem, given a hold-out set  $\mathbf{Z}_{g}$ :

$$
\mathcal {A} _ {g} \left(\mathbf {Z} _ {g}\right): \quad \hat {g} = \arg \min  _ {g \in \mathcal {G} ^ {\prime}} \frac {1}{| \mathbf {Z} _ {g} ^ {\prime} |} \sum_ {(\mathbf {x}, \mathbf {y}) \in \mathbf {Z} _ {g} ^ {\prime}} \frac {1}{| \mathbf {y} |} \sum_ {l = 1} ^ {| \mathbf {y} |} \left| \log f \left(\left(\mathbf {x}, \mathbf {y} _ {1: l - 1}\right), \mathbf {y} _ {l}\right) - \log g \left(\mathbf {x}, \mathbf {y} _ {1: l - 1}\right) \right|, \tag {11}
$$

Here,  $\mathbf{Z}_g^{\prime}$  and  $\mathbf{Z}_g^{\prime \prime}$  are randomly partitioned from  $\mathbf{Z}_g$ , i.e.,  $\mathbf{Z}_g = \mathbf{Z}_g^{\prime} \cup \mathbf{Z}_g^{\prime \prime}$  and  $\emptyset = \mathbf{Z}_g^{\prime} \cap \mathbf{Z}_g^{\prime \prime}$ , where  $\mathbf{Z}_g^{\prime \prime}$  is used to choose the best  $g$ .

Design choice of  $g$ . The neural network  $g: \mathcal{X}^* \to \mathbb{R}$  is part of the parameters of neural prediction set models. Here, we exploit a hidden state of a GLM given an input prompt  $\mathbf{x}$ . In particular, letting  $\mathcal{H}$  be an embedding space of a given GLM, formed by an embedding  $g_1: \mathcal{X}^* \to \mathcal{H}$ , and  $g_2: \mathcal{H} \to \mathbb{R}$  be a neural network, we choose  $g: \mathbf{x} \mapsto g_2(g_1(\mathbf{x}))$ , and learn  $g_2$  in  $\mathcal{A}_g$  of (11), while fixing  $g_1$ .

Algorithm  $\mathcal{A}_{\mathrm{NPS}}$ . The final algorithm, called  $\mathcal{A}_{\mathrm{NPS}}$ , is the composition of  $\mathcal{A}_g$  and  $\mathcal{A}_h$ , i.e.,  $\mathcal{A}_{\mathrm{NPS}}: \mathbf{Z} \mapsto \mathcal{A}_h(\mathcal{A}_g(\mathbf{Z}_g), \mathbf{Z}_h)$ , where  $\mathbf{Z}$  is randomly partitioned into  $\mathbf{Z}_g$  and  $\mathbf{Z}_h$ , i.e.,  $\mathbf{Z} = \mathbf{Z}_g \cup \mathbf{Z}_h$  and

$\emptyset = \mathbf{Z}_g \cap \mathbf{Z}_h$ . Here, we assume  $|\mathbf{Z}_g| = |\mathbf{Z}_h|$ . Interestingly, our algorithm has better sample-complexity to achieve the PAC guarantee with smaller set size, compared to the baseline PAC prediction set algorithm (3). In particular, even though we hold out the half of a calibration set for the heuristic learning of  $g$  and use only half of the set for PAC learning, our algorithm achieves clearly smaller prediction set size, on average, than the baseline algorithm with a full calibration set. See Section 4 for empirical results.

# 3.4 PAC Guarantee

We prove that the proposed algorithm  $\mathcal{A}_{\mathrm{NPS}}$  is PAC. This is the direct consequence of Lemma 1.

Theorem 2. The algorithm  $\mathcal{A}_{NPS}$  is PAC, i.e., for any  $f$ ,  $\varepsilon \in (0,1)$ ,  $\delta \in (0,1)$ , and  $n \in \mathbb{Z}_{\geq 0}$ , we have  $\mathbb{P}\{\mathbb{P}\{\mathbf{y} \notin \hat{C}(\mathbf{x})\} \leq \varepsilon\} \geq 1 - \delta$ , where the inner probability is taken over a labeled example  $(\mathbf{x},\mathbf{y}) \sim \mathbf{D}$ , the outer probability is taken over i.i.d. labeled examples  $\mathbf{Z} \sim \mathbf{D}^n$ , and  $\hat{C} = \mathcal{A}_{NPS}(\mathbf{Z})$ .

Proof. From Lemma 1, for any  $g$ , including the output of  $\mathcal{A}_g$ ,  $\mathcal{A}_h$  is  $(\varepsilon, \delta)$ -PAC. As  $\mathcal{A}_g$  and  $\mathcal{A}_h$  use non-overlapping labeled examples and  $\mathcal{A}_h$  is  $(\varepsilon, \delta)$ -PAC, so  $\mathcal{A}_{\mathrm{NPS}}$  does.

# 3.5 Applications to Uncertainty Quantification of GLMs

The neural prediction sets constructed by the PAC algorithm can be used as the basis of the trust on the quantified uncertainty via the set size. Here, we mainly consider token-wise uncertainty.

Token-wise uncertainty. Suppose that we have  $\hat{C} \in \mathcal{F}$  from our PAC algorithm  $\mathcal{A}_{\mathrm{NPS}}$ , a prompt  $\mathbf{x}$ , and a generated token sequence  $\mathbf{y}_{1:l-1}'$  (from a GLM given  $\mathbf{x}$ ); then we have the following conditional neural prediction set for the  $l$ -th token:

$$
\hat {C} _ {l} \left(\mathbf {x}; \mathbf {y} _ {1: l - 1} ^ {\prime}\right) = \left\{ \begin{array}{l l} \left\{y \in \mathcal {X} \mid f \left(\left(\mathbf {x}, \mathbf {y} _ {1: l - 1} ^ {\prime}\right), y\right) \geq \hat {\tau} \left(\mathbf {x}, \mathbf {y} _ {1: l - 1} ^ {\prime}\right) \right\} & \text {i f} \mathbf {y} _ {1: l - 1} ^ {\prime} \in \hat {C} _ {l - 1} (\mathbf {x}) \\ \mathcal {X} & \text {o t h e r w i s e} \end{array} , \right. \tag {12}
$$

where  $|\hat{C}_l(\mathbf{x};\mathbf{y}_{1:l - 1}')|$  represents the uncertainty of the  $l$ -th token prediction, i.e., the number of alternative tokens for the  $l$ -th token. Here, the uncertainty by the conditional prediction set is probably invalid if  $\mathbf{y}_{1:l - 1}' \notin \hat{C}_{l - 1}(\mathbf{x})$  but we cannot reject its validity otherwise. In particular, the provided PAC guarantee implies  $\mathbb{P}\{\mathbf{y} \in \hat{C}(\mathbf{x})\} \geq 1 - \varepsilon$ , meaning that a true response  $\mathbf{y}$  is likely included in the prediction set  $\hat{C}(\mathbf{x})$ . Thus, if  $\mathbf{y}_{1:l - 1}' \notin \hat{C}_{l - 1}(\mathbf{x})$ , the generated sub-sequence  $\mathbf{y}_{1:l - 1}'$  is unlikely to be the sub-sequence of the true response  $\mathbf{y}$ . In this case, the prediction set returns the entire set  $\mathcal{X}$  to indicate the probable invalidity of the generated subsequence. When  $\mathbf{y}_{1:l - 1}' \in \hat{C}_{l - 1}(\mathbf{x})$ , we cannot reject the possibility that the generated sequence is the true sequence, so we still use the conditional prediction set  $\hat{C}_l(\mathbf{x};\mathbf{y}_{1:l - 1}')$  to quantify the uncertainty of the  $l$ -th token, assuming  $\mathbf{y}_{1:l - 1}'$  is part of the true response.

# 4 Experiments

We empirically justify the efficacy of the proposed method using various datasets and models. See Appendix C and Appendix D for experiment details and additional results, respectively.

Datasets. We evaluate our method in four different types of datasets: common sense reasoning, closed-book question-answering (QA), open-book QA, and mathematical reasoning. In particular, we use PIQA [5], SIQA [33], Hellaswag [44], and BoolQ [8] for the common sense reasoning dataset; TriviaQA [15] for closed-book QA; CoQA [32] for open-book QA; and DeepMath [34] for mathematical reasoning.

GLMs. We use six different GLMs: GPT-2 Small [31], GPT-2 Medium [31], GPT-2 Large [31], LLaMA-7B [36], LLaMA-13B [36], and Alpaca-7B [35]. Here, we use these GLMs as scoring functions and did not fine-tune them.

Methods. We consider a standard baseline, denoted by SPS, along with our method NPS. SPS [39, 26] learns a prediction set via  $\mathcal{A}_{\mathrm{Binom}}$  in (3) with a scalar-parameterized prediction set. Here, SPS and NPS use the same number of calibration examples for fair comparison (i.e.,  $\mathcal{A}_h$  of NPS uses the less number of calibration examples than  $\mathcal{A}_{\mathrm{Binom}}$  of SPS). Here, we use a fully-connected neural network with one hidden layer of 1000 neurons and ReLU for the neural network  $g$  of NPS.

Metrics. Given a test set  $\mathbf{T} \subseteq (\mathcal{X}^* \times \mathcal{X}^*)^*$ , we consider three evaluation metrics: (1) the mean error of a prediction set, i.e., Error :=  $1 / |\mathbf{T}| \sum_{(\mathbf{x},\mathbf{y}) \in \mathbf{T}} \mathbb{1}(\mathbf{y} \notin \hat{C}(\mathbf{x}))$ , (2) the mean of the average normalized-

size of a conditional prediction set, i.e.,  $\mathrm{Size}_{\mathrm{mean}} := \mathrm{mean}_{(\mathbf{x},\mathbf{y})\in \mathbf{T}}\left(1 / |\mathbf{y}|\sum_{l = 1}^{|\mathbf{y}|}\hat{C} (\mathbf{x};\mathbf{y}_{1:l - 1}) / |\mathcal{X}|\right)$ , and (3) the median of the average normalized-size of a conditional prediction set, i.e.,  $\mathrm{Size}_{\mathrm{median}} := \mathrm{median}_{(\mathbf{x},\mathbf{y})\in \mathbf{T}}\left(1 / |\mathbf{y}|\sum_{l = 1}^{|\mathbf{y}|}\hat{C} (\mathbf{x};\mathbf{y}_{1:l - 1}) / |\mathcal{X}|\right)$ .

Discussion. Table 1 summarizes the performance of our method along with the baseline. All prediction set errors of both methods are below of  $\varepsilon = 0.01$ , satisfying the PAC guarantee (i.e., the prediction set error is less than  $\varepsilon$  with probability at least  $1 - \delta$ ; see Figure 5 for details). Also, NPS produces  $63\%$  smaller prediction sets than the baseline on average even though we use the same number of calibration samples ( $n = 50,000$ ) for both methods but NPS holds out the half for learning  $g$ . These justify that NPS satisfies the PAC guarantee, while producing smaller set size than SPS.

Notably, SPS tends to produce vacuous prediction sets for LLaMA-7B and Alpaca-7B models. From Figure 4(b), we observe that these models produce many small conformity scores on true labels in learning (i.e., the models are under-confident), which leads to making the prediction set error larger than  $\varepsilon$ . This results in very small  $\hat{\tau}$  so conservative prediction sets by SPS. Contrast to this, NPS produces meaningful prediction set size, which demonstrates the benefit of a high-dimensional parameterization of prediction sets, which is viable to model a complex structure of conformity scores.

For GPT-2 models, NPS achieves competitive results in size. In particular, SPS produces relatively small set size for GPT-2 models as the conformity scores  $f(\mathbf{x}, \mathbf{y}_{1:l}, \mathbf{y}_l)$  of these models are distributed in a narrow range (e.g., Figure 4(a)). This implies that a simple prediction set parameter could perform well for models with non-diverse conformity scores, though we also observe that NPS with larger calibration set size clearly outperforms SPS in the median set size (see Figure 6 for details).

Figure 3 shows the qualitative results on token-wise uncertainty of Alpaca-7B over TriviaQA. SPS produces non-informative prediction sets, while NPS reasonably quantifies the token-wise uncertainty of the model (i.e., NPS sparsely shows higher uncertainty if the corresponding position has multiple alternative tokens than the generated token). Interestingly, "Bob Dylan" example shows one benefit of the PAC guarantee. As mentioned in Section 3.5, the conditional prediction set can say when a generated token is provably incorrect (i.e., Bob Dylan is not British), as visualized in red backgrounds. See Figure 10 for more results.

# 5 Conclusion

We propose to learn a neural prediction set for quantifying the uncertainty of GLMs, measured by the prediction set size. The proposed learning algorithm comes with the PAC guarantee, the source of trust on the quantified uncertainty. We empirically justify the efficacy of our method in various language datasets and GLMs, in terms of prediction set error and size.

Limitations. As the main limitation, the proposed method relies on the i.i.d. assumption, which can be violated via distribution shift, e.g., adversarial prompts. Extending our method under distribution shift would be an interesting future direction. Additionally, considering beyond token-wise uncertainty (e.g., semantic uncertainty) could provide more user-friendly uncertainty.

Potential negative societal impacts. The proposed method quantifies the uncertainty of GLM responses under the i.i.d. assumption. Understanding this assumption and ways to interpret uncertainty results are required to avoid misunderstanding. As a safeguard, we will provide guidelines to interpret quantified uncertainty results.
