# ABSTRACT

Multi-stage training and knowledge transfer from a large-scale pretrain task to various finetune end tasks have revolutionized natural language processing (NLP) and computer vision (CV), with state-of-the-art performances constantly being improved. In this paper, we develop a multi-stage influence function score to track predictions from a finetune model all the way back to the pretrain data. With this score, we can identify the pretrain examples in the pretrain task that contribute most to a prediction in the finetune task. The proposed multi-stage influence function generalizes the original influence function for a single model in Koh & Liang (2017), thereby enabling influence computation through both pretrain and finetune models. We study two different scenarios with the pretrain embeddings fixed or updated in the finetune tasks. We test our proposed method in various experiments to show its effectiveness and potential applications.

# 1 INTRODUCTION

Multi-stage training has become increasingly important and has achieved state-of-the-art results in many tasks. In NLP applications, it is now a common practice to first learn word embeddings (e.g., word2vec (Mikolov et al., 2013), GloVe (Pennington et al., 2014)) or contextual representations (e.g., ELMo (Peters et al., 2018), BERT (Devlin et al., 2018)) from a large unsupervised corpus, and then refine or finetune the model on supervised end tasks. In computer vision applications, it is common to use a pretrained CNN as a feature extractor and only finetune top-layer networks through training on the end task. Also, it has been demonstrated that pretraining ResNet (He et al., 2016) with large hashtag data can greatly benefit many end tasks (Mahajan et al., 2018). Intuitively, the successes of these multi-stage learning paradigms are due to knowledge transfer from pretrain tasks to the end task. However, current approaches using multi-stage learning are usually based on trial-and-error and many fundamental questions remain unanswered. For example, which part of the pretrain data/task contributes most to the end task? How can one detect "false transfer" where some pretrain data/task could be harmful for the end task? If a testing point is wrongly predicted by the finetune model, can we trace back to the problematic examples in the pretrain data? Answering these questions requires a quantitative measurement of how the data and loss function in the pretrain stage influence the end model, which has not been studied in the past and will be the main focus of this paper.

To find the most influential training data responsible for a model's prediction, the influence function was first introduced by Cook & Weisberg (1980) from a robust statistics point of view. Recently, as large-scale applications become more challenging for influence function computation, Koh & Liang (2017) proposed to use a first-order approximation to measure the effect of removing one training point on the model's prediction, to overcome computational challenges. More broadly, there are many works using influence functions to investigate the impact of training data on models in various machine learning applications, such as tracing back the origins of bias in the word embeddings generated by GloVe (Brunet et al., 2019), and understanding and mitigating disparate impact to improve model fairness (Wang et al., 2019). However, all of the existing influence score computation algorithms study the case of single-stage training – where there is only one model with one set of training/prediction data in the training process. To the best of our knowledge, the influence of pretrain data on a subsequent finetune task and model has not been studied, and it is nontrivial to apply the original influence function in (Koh & Liang, 2017) to this scenario.

In this work, we derive the influence function from pretrain data to the end task in multi-stage training. Since the computation involves several expensive Hessian vector products, we also show how to

compute the influence function efficiently in large-scale problems. Based on this technique, we show that

- in real datasets and experiments across various vision and NLP tasks, predictions using the technique and actual influence for the pretrain data to the finetune model are highly correlated (Pearson's  $r$  score to be around 0.6). This shows the effectiveness of our proposed technique for computing the influence scores in multi-stage models;  
- the influence for the pretrain data to the finetune model can be split into two parts: the influence of the pretrain data on the pretrain model, and influence of the pretrain data on the finetune model. Therefore the testing data from the finetune task will be impacted by changes in the pretrain data, which can be quantified using our proposed technique;  
- the influence of the pretrain data on the finetune task is highly dependent on 1) the similarity of two tasks or stages, 2) and the number of training data in the finetune task. Thus our proposed technique provides a novel way to measure how the pretrain data helps or benefits the finetune data.

# 2 RELATED WORK

Multi-stage model training that trains models in many stages on different tasks to improve the end-task has been used widely in many machine learning areas, such as in transfer learning (Ando & Zhang, 2005) and zero-shot learning (Larochelle et al., 2008). Recently, multi-stage model training has achieved state-of-the-art performance by learning large embeddings or data representation as the pretrain step on a very large pretrain dataset, which is then followed by a finetune step with further training on the end-task. Examples include the recently proposed BERT (Devlin et al., 2018), which learns contextual embeddings on a large corpus with the pretrain tasks chosen to be predicting the masked words in a sentence and predicting whether one sentence is after another sentence. This contextual embedding is then used in finetune tasks, such as a question answering task. ELMo (Peters et al., 2018) is widely used in multi-stage model training as a sentence feature extractor to benefit the end-task. Similarly, there are some works in computer vision that train an image representation model on a large number of images as the pretrain step, and then use the resulting features to finetune another task, such as particular image classification tasks. For example, (Mahajan et al., 2018) uses ResNet in the pretrain step, and the finetune task is based on hashtag data. The rationale for this multi-stage model is that the pretrain task can learn some common or latent representation which could benefit the end task.

Another related line of research is on understanding machine learning models. One category of research is to explain predictions with respect to model variables, and trace back the contribution of variables to the prediction. For example, Oramas et al. (2019) automatically detects internal features in the set of classes in the pretrain model that are relevant to interpreting the prediction, and shows for various vision tasks that the proposed scheme can produce detailed explanations based on the features that are relevant to the targeted classes. Guo et al. (2019) aims to interpret variable-wise hidden states in an LSTM model to quantify variable importance and variable-wise temporal importance in the model.

Closely related research has sought to connect model prediction and training data, and trace back the most influential training data that are most responsible for the model prediction. Among them, the influence function (Cook & Weisberg, 1980; Koh & Liang, 2017), which aims to model the prediction changes when training data is added/removed, has been shown to be effective in many applications. There is a series of work on influence functions, including investigating the influence of a group of data on the prediction (Koh et al., 2019), using influence functions to detect bias in word embeddings (Brunet et al., 2019), and using it in preventing data poisoning attacks (Steinhardt et al., 2017), etc. All of these works only consider a single stage training procedure, and it is not straightforward to apply the existing influence functions to multi-stage models. In this paper, we propose to analyze the influence of pretrain data on predictions in the subsequent finetune model and end task.

# 3.1 MULTI-STAGE MODEL TRAINING

Multi-stage models, which train different models in consecutive stages, have been widely used in various ML tasks. Mathematically, let  $\mathcal{Z}$  be the training set for pretrain task with data size  $|\mathcal{Z}| = m$ , and  $\mathcal{X}$  be the training data for the finetune task with data size  $|\mathcal{X}| = n$ . In pretrain stage, we assume the parameters of the pretrain network have two parts: the parameters  $W$  that are shared with the end task, and the task-specific parameters  $U$  that will only be used in the pretrain stage. Note that  $W$  could be a word embedding matrix (e.g., in word2vec) or a representation extraction network (e.g., Elmo, BERT, ResNet), while  $U$  is usually the last few layers that corresponds to the pretrain task. After training on the pretrain task, we obtain the optimal parameters  $W^{*}, U^{*}$ . The pretrain stage can be formulated as

$$
\text {P r e t r a i n S t a g e :} \quad W ^ {*}, U ^ {*} = \underset {W, U} {\arg \min } \frac {1}{m} \sum_ {z \in \mathcal {Z}} g (z, W, U) := \underset {W, U} {\arg \min } G (W, U), \tag {1}
$$

where  $g(\cdot)$  is the loss function for the pretrain task.

In the finetune stage, the network parameters are  $W$ ,  $\Theta$ , where  $W$  is shared with the pretrain task and  $\Theta$  is the rest of the parameters specifically associated with the finetune task. We will initialize the  $W$  part by  $W^{*}$ . Let  $f(\cdot)$  denote the finetune loss, there are two cases when finetune the end-task:

- Finetune Case 1: Fixing embedding parameters  $W = W^{*}$ , and only finetune  $\Theta$ :

$$
\Theta^ {*} = \underset {\Theta} {\arg \min } \frac {1}{n} \sum_ {x \in \mathcal {X}} f (x, W ^ {*}, \Theta) := \underset {\Theta} {\arg \min } F \left(W ^ {*}, \Theta\right). \tag {2}
$$

- Finetune Case 2: finetune both the embedding parameters  $W$  (initialized from  $W^{*}$ ) and  $\Theta$ . Sometimes updating the embedding parameters  $W$  in the finetune stage is necessary, as the embedding parameters from the pretrain model may not be good enough for the finetune task. This corresponds to the following formulation:

$$
W ^ {* *}, \Theta^ {*} = \arg \min  _ {W, \Theta} \frac {1}{n} \sum_ {x \in \mathcal {X}} f (x, W, \Theta) := \underset {W, \Theta} {\arg \min } F (W, \Theta). \tag {3}
$$

# 3.2 INFLUENCE FUNCTION FOR MULTI-STAGE MODELS

We derive the influence function for the multi-stage model to trace the influence of pretrain data on the finetune model. In Figure 1 we show the task we are interested in solving in this paper. Note that we use the same definition of influence function as (Koh & Liang, 2017) and discuss how to compute it in the multi-stage training scenario. As discussed at the end of Section 3.1, depending on whether or not we are updating the shared parameters  $W$  in the finetune stage, we will derive the influence functions under two different scenarios.

# 3.2.1 CASE 1: EMBEDDING PARAMETERS  $W$  ARE FIXED IN FINETUNE

To compute the influence of pretrain data on the finetune task, the main idea is to perturb one data example in the pretrain data, and study how that impacts the test data. Mathematically, if we perturb

a pretrain data example  $z$  with loss change by a small  $\epsilon$ , the perturbed model can be defined as

$$
\hat {W} _ {\epsilon}, \hat {U} _ {\epsilon} = \underset {W, U} {\arg \min } G (W, U) + \epsilon g (z, W, U). \tag {4}
$$

Note that choices of  $\epsilon$  can result in different effects in the loss function from the original solution in (1). For instance, if we set  $\epsilon = -\frac{1}{n}$ , then we are removing the training data  $z$  in the pretrain dataset.

For the finetune stage, since we consider Case 1 where the embedding parameters  $W$  are fixed in the finetune stage, the new model for the end-task or finetune task will thus be

$$
\hat {\Theta} _ {\epsilon} = \underset {\Theta} {\arg \min } F (\hat {W} _ {\epsilon}, \Theta). \tag {5}
$$

The influence function that measures the impact of a small  $\epsilon$  perturbation on  $z$  to the finetune loss on a test sample  $x_{t}$  from finetune task is defined as

$$
\begin{array}{l} I _ {z, x _ {t}} := \frac {\partial f \left(x _ {t} , \hat {W} _ {\epsilon} , \hat {\Theta} _ {\epsilon}\right)}{\partial \epsilon} | _ {\epsilon = 0} (6) \\ = \nabla_ {\Theta} f \left(x _ {t}, W ^ {*}, \Theta^ {*}\right) ^ {T} \cdot I _ {z, \Theta} + \nabla_ {W} f \left(x _ {t}, W ^ {*}, \Theta^ {*}\right) ^ {T} \cdot I _ {z, W}. (7) \\ \end{array}
$$

$$
\left. \text {w i t h} I _ {z, \Theta} := \frac {\partial \hat {\Theta} _ {\epsilon}}{\partial \epsilon} \right| _ {\epsilon = 0} \text {a n d} I _ {z, W} := \left. \frac {\partial \hat {W} _ {\epsilon}}{\partial \epsilon} \right| _ {\epsilon = 0}, \tag {8}
$$

where  $I_{z,\Theta}$  measures the influence of  $z$  on the finetune task parameters  $\Theta$ , and  $I_{z,W}$  measures how  $z$  influences the pretrain model  $W$ . Therefore we can split the influence of  $z$  on the test sample into two pieces: one is the impact of  $z$  on the pretrain model  $I_{z,W}$ , and the other is the impact of  $z$  on the finetune model  $I_{z,\Theta}$ . It is worth mentioning that, due to linearity, if we want to estimate a set of test example influence function scores with respect to a set of pretrain examples, we can simply sum up the pair-wise influence functions, and so define

$$
I _ {\{z ^ {(i)} \}, \left\{x _ {t} ^ {(j)} \right\}} := \sum_ {i} \sum_ {j} I _ {z ^ {(i)}, x _ {t} ^ {(j)}}. \tag {9}
$$

where  $\{z^{(i)}\}$  and  $\{x_t^{(j)}\}$  contain a set of pretrain training data and finetune test data. Next we will derive these two influence scores  $I_{z,\Theta}$  and  $I_{z,W}$  (see the detailed derivations in the appendix) in Theorem 1 below.

Theorem 1. For the two-stage training procedure in (1) and (2), we have

$$
\begin{array}{l} I _ {z, W} := \left. \frac {\partial \hat {W} _ {\epsilon}}{\partial \epsilon} \right| _ {\epsilon = 0} = - \left[ \left(\frac {\partial^ {2} G (W ^ {*} , U ^ {*})}{\partial (W , U) ^ {2}}\right) ^ {- 1} \left(\frac {\partial g (z , W ^ {*} , U ^ {*})}{\partial (W , U)}\right) \right] _ {W} \tag {10} \\ I _ {z, \Theta} := \frac {\partial \hat {\Theta} _ {\epsilon}}{\partial \epsilon} \big | _ {\epsilon = 0} = (\frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta^ {2}}) ^ {- 1} \cdot (\frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta \partial W}) \cdot \left[ (\frac {\partial^ {2} G (W ^ {*} , U ^ {*})}{\partial (W , U) ^ {2}}) ^ {- 1} (\frac {\partial g (z , W ^ {*} , U ^ {*})}{\partial (W , U)}) \right] _ {W} \\ \end{array}
$$

where  $[\cdot ]_W$  means taking the  $W$  part of the vector.

By plugging (10) into (7), we finally obtain the influence score of pretrain data  $z$  on the finetune task testing point  $x_{t}, I_{z,x_{t}}$  as

$$
I _ {z, x _ {t}} = \left[ \frac {\partial f (x , W ^ {*} , \Theta^ {*}) ^ {T}}{\partial \Theta} \cdot \left(\frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta^ {2}}\right) ^ {- 1} \cdot \frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta \partial W} - \frac {\partial f (x , W ^ {*} , \Theta^ {*}) ^ {T}}{\partial W} \right] I _ {z, W} \tag {11}
$$

Algorithm 1 shows how to compute the influence score in (11). The pseudocode for computing the influence function in (11) is shown in Algorithm 1.

# 3.2.2 CASE 2: EMBEDDING PARAMETER  $W$  IS ALSO UPDATED IN THE FINETUNE STAGE

For the second finetune stage case in (3), we will also further train the embedding parameter  $W$  from the pretrain stage. When  $W$  is also updated in the finetune stage, it is challenging to characterize the influence since the pretrain embedding  $W^{*}$  is only used as an initialization. In general, the final model  $(W^{**},\Theta^{*})$  may be totally unrelated to  $W^{*}$ ; for instance, when the objective function is strongly convex, any initialization of  $W$  in (3) will converge to the same solution.

2 Output: Influence function value  $I_{z,x_t}$  
3 Compute fintune model's gradients  $\frac{\partial f(x_t,W^*,\Theta^*)}{\partial\Theta}$  and  $\frac{\partial f(x_t,W^*,\Theta^*)}{\partial W}$ ;  
4 Compute the first inverse Hessian vector product  $V_{ihvp1}(x_t)\coloneqq (\frac{\partial^2F(W^*,\Theta^*)}{\partial\Theta^2})^{-1}\frac{\partial f(x_t,W^*,\Theta^*)}{\partial\Theta};$  
5 Compute finetune loss's gradient w.r.t  $W$ :  $\frac{\partial f(x_t,W^*,\Theta^*)^T}{\partial W} = V_{ihvp1}^T\frac{\partial^2F(W^*\Theta^*)}{\partial\Theta\partial W} -\frac{f(x_t,W^*,\Theta^*)}{\partial W}$  and concatenate it with 0 to make it the same dimension as  $(W,U)$ ;  
6 Compute and save the second inverse Hessian vector product

$$
V _ {i h v p 2} ^ {T} \left(x _ {t}\right) := \left[ \frac {\partial f \left(x _ {t} , \Theta^ {*} , W ^ {*}\right) ^ {T}}{\partial W}, 0 \right] \left(\frac {\partial^ {2} G \left(W ^ {*} , U ^ {*}\right)}{\partial \left(W , U\right) ^ {2}}\right) ^ {- 1};
$$

7 Compute influence function score  $I_{z,x_t} = V_{ihvp2}^T(x_t) \frac{\partial g(z,W^*,U^*)}{\partial(W,U)}$ ;

However, in practice the initialization of  $W$  will strongly influence the finetune stage in deep learning, since the finetune objective is usually highly nonconvex and initializing  $W$  with  $W^{*}$  will converge to a local minimum near  $W^{*}$ . Therefore, we propose to approximate the whole training procedure as

$$
\bar {W}, \bar {U} = \underset {W, U} {\arg \min } G (W, U) \tag {12}
$$

$$
W ^ {*}, \Theta^ {*} = \underset {W, \Theta} {\arg \min} \{\alpha \| W - \bar {W} \| _ {F} ^ {2} + F (W, \Theta) \},
$$

where  $\bar{W},\bar{U}$  are optimal for the pretrain stage,  $W^{*},\Theta^{*}$  are optimal for the finetune stage, and  $0\leq \alpha \ll 1$  is a small value. This is to characterize that in the finetune stage, we are targeting to find a solution that minimizes  $F(W,\Theta)$  and is close to  $\bar{W}$ . In this way, the pretrain parameters are connected with finetune task and thus influence of pretrain data to the finetune task can be tractable. The results in our experiments show that with this approximation, the computed influence score can still reflect the real influence quite well.

Similarly we can have  $\frac{\partial\hat{\Theta}_{\epsilon}}{\partial\epsilon},\frac{\partial\hat{W}_{\epsilon}}{\partial\epsilon}$ , and  $\frac{\partial\bar{W}_{\epsilon}}{\partial\epsilon}$  to measure the difference between their original optimal solutions in (12) and the optimal solutions from  $\epsilon$  perturbation over the pretrain data  $z$ . Similar to (7), the influence function  $I_{z,x_t}$  that measures the influence of  $\epsilon$  perturbation to pretrain data  $z$  on test sample  $x_{t}$ 's loss is

$$
I _ {z, x _ {t}} := \frac {\partial f \left(x _ {t} , \hat {W} _ {\epsilon} , \hat {\Theta} _ {\epsilon}\right)}{\partial \epsilon} | _ {\epsilon = 0} = \frac {\partial f \left(x _ {t} , W ^ {*} , \Theta^ {*}\right) ^ {T}}{\partial (W , \Theta)} \left[ \begin{array}{c} \frac {\partial \hat {W} _ {\epsilon}}{\partial \epsilon} | _ {\epsilon = 0} \\ \frac {\partial \hat {\Theta} _ {\epsilon}}{\partial \epsilon} | _ {\epsilon = 0} \end{array} \right]. \tag {13}
$$

The influence function of small perturbation of  $G(W,U)$  to  $\bar{W}$ ,  $W^{*}$ ,  $\Theta^{*}$  can be computed following the same approach in Subsection 3.2.1 by replacing  $\bar{W}$  for  $W^{*}$  and  $[\Theta^{*},W^{*}]$  for  $\Theta^{*}$  in (10). This will lead to

$$
\left. \frac {\partial \bar {W} _ {\epsilon}}{\partial \epsilon} \right| _ {\epsilon = 0} = - \left[ \left(\frac {\partial^ {2} G (\bar {W} , \bar {U})}{\partial (W , U) ^ {2}}\right) ^ {- 1} \left(\frac {\partial g (z , \bar {W} , \bar {U})}{\partial (W , U)}\right) \right] _ {W} \tag {14}
$$

$$
\left[ \begin{array}{c} \frac {\partial \hat {\Theta} _ {\epsilon}}{\partial \epsilon} \Big | _ {\epsilon = 0} \\ \frac {\partial \hat {W} _ {\epsilon}}{\partial \epsilon} \Big | _ {\epsilon = 0} \end{array} \right] = \left[ \begin{array}{c c} \frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta^ {2}} & \frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta \partial W} \\ \frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial \Theta \partial W} & \frac {\partial^ {2} F (W ^ {*} , \Theta^ {*})}{\partial W ^ {2}} + 2 \alpha I \end{array} \right] ^ {- 1} \left[ \begin{array}{c} 0 \\ - 2 \alpha I \end{array} \right] \left[ \left(\frac {\partial^ {2} G (\bar {W} , \bar {U})}{\partial (W , U) ^ {2}}\right) ^ {- 1} (\frac {\partial g (z , \bar {W} , \bar {U})}{\partial (W , U)}) \right] _ {W}
$$

After plugging (14) into (13), we will have the influence function  $I_{z,x_t}$ . Similarly, the algorithm for computing  $I_{z,x_t}$  for Case 2 can follow Algorithm 1 for Case 1 by replacing gradient computation.

# 3.3 IMPLEMENTATION DETAILS

The influence function computation for multi-stage model is presented in the previous section. As we can see in Algorithm 1 that the influence score computation involves many Hessian matrix operations, which will be very expensive and sometimes unstable for large-scale models. We used several strategies to speed up the computation and make the scores more stable.

Large Hessian Matrices A Hessian matrix  $H$  has a size of  $p \times p$ , where  $p$  is the number of parameters in the model. For large deep learning models with thousands or even millions of parameters, it

is almost impossible to fit a  $p \times p$  Hessian into memory. Also, to invert a Hessian requires  $O(p^3)$  operations. Similar to Koh & Liang (2017), we avoid explicitly computing and storing the Hessian matrix and its inverse, and instead compute product of the inverse Hessian with a vector directly. Every time we need an inverse Hessian vector product  $v = H^{-1}b$ , we invoke conjugate gradients (CG), which transforms the linear system problem into an quadratic optimization problem

$$
H ^ {- 1} b \equiv \underset {x} {\arg \min } \left\{\frac {1}{2} x ^ {T} H x - b ^ {T} x \right\}. \tag {15}
$$

In each iteration of CG, instead of computing  $H^{-1}b$  directly, we will compute a Hessian vector product, which can be efficiently done by backprop through the model twice with  $O(p)$  time complexity. The aforementioned conjugate gradient method requires the Hessian matrix to be positive definite. However, in practice the Hessian may have negative eigenvalues, since we run a SGD and the final  $H$  may not at a local minimum exactly. To tackle this issue, we solve  $\arg \min_{x}\{\frac{1}{2} x^{T}H^{2}x - b^{T}Hx\}$ , whose solution can be shown the same as (15) since the Hessian matrix is symmetric.  $H^2$  is guaranteed to be positive definite as long as  $H$  is not singular. The rate of convergence of the conjugate gradient depends on  $\frac{\sqrt{\kappa(H^2)} - 1}{\sqrt{\kappa(H^2)} + 1}$ , where  $\kappa (H^2)$  is the condition number of  $H^2$ , which can be very large if  $H$  is ill-conditioned. To encourage faster convergence, we add a small damping term  $\lambda$  on the diagonal and solve  $\arg \min_{x}\{\frac{1}{2} x^{T}(H^{2} + \lambda I)x - b^{T}Hx\}$ .

Time Complexity As mentioned above, we can get an inverse Hessian vector product in  $O(p)$  time. Since  $F$  and  $G$  are summation of loss with respect to all pretrain or finetune examples, it takes  $O(mp)$  or  $O(np)$  to compute Hessian vector product, where  $m$  is the number of pretrain examples and  $n$  is the number of finetune examples. We may subsample the pretrain examples to estimate  $G(W,U)$  when the number of pretrain examples is gigantic such as pretrain using One-Billion-word dataset (Chelba et al., 2013) for ELMo etc. For the inverse Hessian vector product, the time complexity is  $O(npr)$ , where  $r$  is the number of iterations in CG.

# 4 EXPERIMENTS

In this section, we will conduct experiment with real datasets on both vision and NLP tasks to show the effectiveness of our proposed influence function. We will show the results in the main text on the vision tasks, and some qualitative results on NLP task related to ELMo are presented in Section C in Appendix.

# 4.1 INFLUENCE FUNCTION CORRELATION WITH REAL SCORE

To show that our proposed influence score are a good approximation, we evaluate our proposed multi-stage influence function on two CNN models with CIFAR and MNIST datasets. The model structures are shown in Table A in Appendix. We use Tanh for all activations. For both MNIST and CIFAR models, CNN layers are used as embeddings and fully connected layers are task-specific. At the pretrain stage, we train the models with examples from only two classes ("bird" vs. "frog") for CIFAR and four classes (0, 1, 2, and 3) for MNIST. The resulting embedding is used in the finetune tasks, where we finetune the model with the examples from the remaining eight classes in CIFAR or the other 6 numbers in MNIST task for classification. In order to make the experiments closer to typical real finetune situations, we reduce the size of the training set in the finetune task by subsampling.

In this experiment we test the correlation between individual pretrain example's multi-stage influence function and the real loss difference when the pretrain examples are removed. We test two cases (as mentioned in Section 3.1) – where the pretrain embedding is fixed, and where it is updated during finetune. For both MNIST and CIFAR, we first train the embedding with the binary classification for  $T_{\mathrm{pretrain}}$  steps. The embedding is then used in the finetune model. Then we train the finetune model for  $T_{\mathrm{finetune}}$  steps. Depending on different scenarios which will be explained below, the embedding may be fixed or updated in the finetune task training. For a given example in the pretrain data, we calculate its influence function score with respect to each test example in the finetune task test set using the method presented in Section 3. To evaluate this pretrain example's contribution to the

overall performance of the model, we sum up the influence function scores across the whole test set in the finetune task.

To validate the score, we remove that pretrain example and go through the aforementioned process again by updating the model. In the updating process we further train the pretrain and finetune models for  $T_{\text{pretrain}}'$  and  $T_{\text{finetune}}'$  steps from the original model checkpoints. Note that in this process the pretrain is conducted with the new leave-one-out pretrain set, while the training set for the finetune task is intact. Due to computation constraints, we only use the top 100 pretrain examples with the largest influence function absolute values in this experiments to get 100 score-difference pairs. Then we run a linear regression between the true loss difference values obtained and the influence score computed to show their correlation. The detailed hyperparameters used in these experiments are presented in Appendix B.

# 4.2 FINETUNE TASK SIMILARITY TO THE PRETRAIN TASK

In this experiment, we explore the relationship between influence function score and finetune task similarity with the pretrain task. Specifically, we study whether the influence function score will increase in absolute value if the finetune task is very similar to the pretrain task. To do this, we use the CIFAR embedding obtained from a "bird vs. frog" classification and test its influence function core on two finetune tasks. The finetune task A is exactly the same as the pretrain "bird vs. frog" classification, while the finetune task B is a classification on two other classes ("automobile vs. deer"). All hyperparameters used in the two finetune tasks are the same. In Figure 6, for both tasks we plot the distribution of the influence function values with respect to each pretrain example. We sum up the influence score for all test examples. We can see that, the first finetune task influence function has much larger absolute values than that of the second task. The average absolute value of task A influence function score is 0.055, much larger than that of task B, which is 0.025. This supports the argument that if pretrain task and finetune task are similar, the pretrain data will have larger influence on the finetune task performance.

# 4.3 INFLUENCE FUNCTION SCORE WITH DIFFERENT NUMBER OF FINETUNE EXAMPLES

We also study the relationship between the influence function scores and number of examples used in finetune. In this experiment, we update the pretrain embedding in finetune stage. We use the same pretrain and finetune task as in Section 4.1. In Figure 7, model C is the model used in Section 4.1.2 while in model D we triple the number of finetune examples as well as the number of finetune steps. Figure 7 demonstrates the distribution of each pretrain examples' influence function score with the whole test set. The average absolute value of influence function score in model D is 0.15, much less than that of model C. This indicates that with more finetune examples and more finetune steps, the influence of pretrain data to the finetune model's performance will decrease. This makes sense as if the finetune data does not have sufficient information for training a good finetune task, then pretrain data will have more impact on the finetune task.

# 5 CONCLUSION

We introduce a multi-stage influence function to evaluate pretrain examples' contribution to finetune model's prediction. Two different cases are studied: the pretrain embedding is fixed in finetune or the pretrain embedding is updated in finetune. We test our method on both CV and NLP tasks. Our experimental results show strong correlation between the proposed multi-stage influence function scores and the true loss difference when an example is removed from the pretrain data. We believe this is a promising way to connect finetune model's performance with pretrain data directly.
